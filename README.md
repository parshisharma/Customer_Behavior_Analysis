# Data Analytics Project

## 1. Overview

This project demonstrates the complete data analytics process, from loading and cleaning raw data to analyzing it and presenting insights through an interactive Power BI dashboard.

The goal is to identify trends, understand patterns, and generate meaningful insights using Python, SQL, and Power BI.

## 2. Dataset

The dataset is used to explore business data and answer important analytical questions.

- **Source:** Attached within
- **Format:** CSV / Excel
- **Size:** 3900 rows and 18 columns originally

## 3. Tools & Technologies

- **Python:** Data loading, cleaning, and Exploratory Data Analysis (EDA)
- **Pandas & NumPy:** Data manipulation and analysis
- **Matplotlib & Seaborn:** Data visualization
- **SQL:** Querying and analyzing data using PostgreSQL, MySQL, or SQL Server
- **Power BI:** Interactive dashboard development
- **Gamma:** Creating a presentation to communicate project findings

## 4. Project Steps

1. **Data Loading:** Imported the dataset into Python using Pandas.
2. **Exploratory Data Analysis (EDA):** Examined data distributions, patterns, trends, and relationships.
3. **Data Cleaning:** Handled missing values, duplicate records, inconsistent formats, and incorrect data types where necessary.
4. **SQL Analysis:** Used SQL queries, aggregations, joins, and filtering to answer analytical questions.
5. **Dashboard Development:** Built an interactive Power BI dashboard with key metrics, charts, and filters.
6. **Reporting:** Summarized the findings and business insights in a report.
7. **Presentation:** Created a PowerPoint presentation using Gamma to communicate the results.

## 8. How to Run

### Prerequisites
- Python 3.x
- Jupyter Notebook or VS Code
- Required Python libraries
- PostgreSQL, MySQL, or SQL Server
- Power BI Desktop

### Setup

1. Clone the repository:

   ```bash
   git clone <your-repository-url>
   ```

2. Navigate to the project folder:

   ```bash
   cd data-analytics-project
   ```

3. Install the required Python libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn sqlalchemy jupyter
   ```

4. Open and run the Jupyter Notebook containing the data cleaning and EDA steps.

5. Import the cleaned dataset into your SQL database and execute the queries in the `sql/` folder.

6. Open the Power BI file to explore the dashboard.

7. Review the report and presentation to understand the final findings.

**Note:** Configure your database connection details before running SQL-related scripts. Keep passwords and other credentials out of the repository.
